# Step 6.2 — Documentare l'installer NSIS non firmato

**Fase:** 6 — Distribuzione
**Stato:** DA FARE
**Dipende da:** step-6.1.md

## Task originale

L'installer NSIS non è firmato: Windows SmartScreen mostrerà un avviso.
Documentarlo nel README (la firma richiede un certificato a pagamento; per
uso personale si accetta l'avviso).

## Contesto

Solo lavoro di documentazione in [README.md](../README.md), nessun codice.
Non comprare un certificato di firma codice per questo progetto a meno che
l'uso cambi da personale a distribuzione più ampia.

## Criterio di uscita

Una sezione nel README spiega l'avviso SmartScreen e perché è accettato.
